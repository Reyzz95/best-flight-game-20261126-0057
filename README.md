Skybound Aces is a pseudo-3D flight game featuring procedural terrain, glowing rings to collect, smooth runway landings, a lit HUD, and three levels of increasing difficulty.

## How to play

- **Controls:** Arrow keys or WASD to steer (bank and pitch), Shift to boost, Space to start, P to pause, R to restart.
- **Levels & Objective:** 3 progressive levels featuring 5, 8, and 12 glowing rings respectively. Fly through all rings and perform a smooth landing on the runway to complete each level.

## Run it

```sh
node serve.ts
```
